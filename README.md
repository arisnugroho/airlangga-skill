# airlangga-skill
claude 2D &amp; 3D
Pembuat video explainer motion graphics yang durasinya menyesuaikan voiceover, maksimal 180 detik (MP4, H.264 + AAC, 30 fps), dari sebuah topik. Mendukung dua gaya visual, yaitu 2D editorial (default) dan 3D voxel gaya Minecraft. Claude menulis naskah voiceover lebih dulu, lalu menawarkan dan menanyakan aset (suara voiceover, file .srt, gambar pendukung, video referensi, musik latar), menyinkronkan semuanya, me-render MP4, dan memverifikasi durasi file hasil render. Gunakan skill ini setiap kali user ingin membuat video motion graphic, video explainer animasi, animasi 3D, video gaya Minecraft atau voxel atau blok, kinetic typography, video penjelasan singkat dari sebuah topik, atau menyebut "buatkan motion graphic tentang ...", "video penjelasan singkat", atau mengunggah file bernama "Referensi Motion Graphic", "gambar1/gambar2", "Suara Voiceover", "VO.mp3", "VO.srt" untuk dijadikan video, meskipun user tidak menyebut nama skill ini. Seluruh komunikasi dengan user memakai Bahasa Indonesia.
